# Website Thuong Mai Dien Tu Nong San Sach (Organic Farm Ecommerce)

- Backend Framework: Laravel 10 (PHP 8.1+) + Laravel Sanctum + Spatie Permission
- Frontend Framework: React.js (Vite) + Tailwind CSS + Lucide Icons + Chart.js
- Database: MySQL
- Media Storage: Cloudinary API
- Integrations: MoMo Payment API Developer Sandbox, Google Distance Matrix API
